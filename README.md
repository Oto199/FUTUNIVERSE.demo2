## 💻 Web Platform Overview

The web platform is built with modern full-stack web technologies:
* **Framework:** React + Vite + TypeScript
* **Styling:** Tailwind CSS with custom neon cyan (#00e5ff) visual accents & dark mode aesthetics
* **Languages:** Full bilingual support for **Georgian (`ka`)** and **English (`en`)**
* **Key Features:**
  * **Dynamic Catalog & Search:** Instant search across player names, kit types, and teams
  * **Filters:** Filter by Team, Player, Kit Type (Player Version, Fan Version, Retro), and Size
  * **Player & Team Landing Pages:** Dedicated showcases for players (Wirtz, Mainoo, Zidane, etc.) and national teams
  * **Admin Panel:** Managing products, uploading kit photos, selecting available sizes, and writing football articles
